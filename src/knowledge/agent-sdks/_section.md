Addendum on programmatic agent runtimes — SDKs that let you drive agents from code rather than
a chat UI. Maturity varies across vendors. Goes deep on one primary SDK (a Copilot callout) and
notes multi-language support with unified JSON-RPC communication as a common pattern. This deck
itself uses the GitHub Copilot SDK to power its dev-only Deck Assistant.
