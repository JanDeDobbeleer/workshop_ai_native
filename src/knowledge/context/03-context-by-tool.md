Every tool combines **implicit context** (open files, workspace index) with **explicit
attachments** you add per prompt. The slide shows a per-tool matrix of how to attach files and
how indexing works in each assistant. The takeaway is that "context" is not one thing — some
arrives automatically from what you have open and what the tool has indexed, and some you add
deliberately for a given request.
