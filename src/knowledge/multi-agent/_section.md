Parallel orchestration of multiple agents: where "Agents & Skills" ends and multi-agent
begins. Introduces a five-step loop — define → delegate → parallelize → isolate → synthesize —
and when parallelism helps versus hurts (only when tasks are truly independent). Covers
hub-and-spoke delegation, an independence test, and using git worktrees so parallel agents
never share a working tree.

Source links:
- **github.com/github/app**: the GitHub Copilot desktop app, an agent-native experience for
  running and orchestrating coding agents.
- **docs.devin.ai**: Devin's documentation, an example autonomous multi-agent system.
