Concrete things people build with MCP: **Blender-MCP** lets Claude control Blender for
prompt-assisted 3D modeling; **enterprise chatbots** connect to many databases so users query
data in natural language; **personal assistants** reach Google Calendar and Notion; and
**Figma → web apps** where Claude Code generates a whole app from a Figma design.

Source links: official docs (modelcontextprotocol.io), the public **MCP Registry**
(registry.modelcontextprotocol.io) for discovering servers, and Microsoft's **MCP for
Beginners** course for learning.
