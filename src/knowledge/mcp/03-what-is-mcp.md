Model Context Protocol (MCP) is an open-source standard for connecting AI applications to
external systems — data sources, tools, and workflows. The slide's analogy: just as USB-C is a
standardized port for devices, MCP is a standardized way to connect AI apps to external
systems. It was introduced in November 2024 by Anthropic. Its purpose is to let LLM
applications integrate with external data sources and tools without a bespoke integration for
each pairing. Official docs: modelcontextprotocol.io.
