title: What Can MCP Connect To?

An MCP server exposes three kinds of primitives, each with a different control model.
**Resources** are data and content clients can read (files, database records, API responses) —
*application-controlled*. **Tools** are executable functions the LLM can invoke (search,
calculators, external actions) — *model-controlled*. **Prompts** are predefined templates for
standardized interactions (workflow templates, domain prompts, reusable patterns) —
*user-controlled*. Real connections include Google Calendar, Notion, Figma, Blender, GitHub,
Slack, databases, and web browsers.
