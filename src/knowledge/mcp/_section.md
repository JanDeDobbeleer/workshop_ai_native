The Model Context Protocol — an open standard (introduced November 2024 by Anthropic) for
connecting AI applications to external systems: data sources, tools, and workflows. Framed as
"USB-C for AI," it turns an M×N integration problem into M+N. Covers the host/client/server
architecture, what MCP exposes (resources, tools, prompts), real-world examples, MCP Apps
(interactive UI in chat), per-tool config paths, and publishing a server to the official
registry.

Source links:
- **modelcontextprotocol.io** / **registry.modelcontextprotocol.io**: official docs and the
  public server registry.
- **microsoft/mcp-for-beginners**: a learning course.
- **ext-apps API** and **VS Code MCP Apps blog**: the MCP Apps extension for interactive UI.
- **docs.github.com — MCP in Copilot**: registering MCP servers in Copilot.
- **ohmyposh.dev/api/mcp**: a live, public, registry-published MCP server (theme validator).
