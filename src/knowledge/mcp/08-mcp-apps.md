MCP Apps extend the protocol so MCP servers can display interactive UI inside conversational
clients/chatbots. Plain MCP tools return text and structured data; MCP Apps add a standardized
way to render richer UI such as charts and visualizations, forms and inputs, and video players.

Source links: the **MCP Apps API** (ext-apps) reference, and the **VS Code MCP Apps support**
blog announcing client support.
