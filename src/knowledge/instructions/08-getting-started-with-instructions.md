Start from widely available best-practice instructions as a baseline rather than a blank file.
Key principles: use Markdown headers for emphasis and agent guidance, keep instructions concise,
establish a baseline to understand prompting techniques, and favor clarity over
comprehensiveness. Helpful resources: **GitHub Awesome Copilot Instructions** (community
examples — the source link), VS Code's built-in "Generate Workspace Instructions File," and
learning from open-source projects. Goal: establish a baseline and understand prompting
techniques before customizing for your needs.
