Anatomy of an effective instructions file, shown with a `.github/copilot-instructions.md`
example covering Code Style, Conventions, Project Structure, and Testing. **Do:** keep
instructions short and specific, use natural language, organize with Markdown headers, include
examples when helpful, and version-control them. **Don't:** write essays, include sensitive
information, contradict yourself, or expect 100% compliance. Pro tip: VS Code can generate a
starting point via **Configure Chat → Generate Chat Instructions**, which analyzes your
codebase.
