Custom instructions are context that persists: define standards once and every agent session
inherits them automatically. The slide frames three *concepts* (deliberately not filenames):
**project-wide rules** that apply everywhere in the repo, **scoped rules** that apply only to
certain files or folders, and a **cross-tool convention** — one file that multiple tools read.
Thinking in concepts first (rather than a specific filename) is what makes the guidance
portable across Copilot, Claude, Cursor, and others, each of which maps these concepts to its
own paths.
