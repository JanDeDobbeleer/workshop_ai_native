The harness is the flow around the model — everything between the request and the result. It
loads context, gives tool access, runs checks, blocks unsafe actions, and decides whether the
agent may finish or must keep working.

The section now teaches the concept in four simple steps: what a harness is, the basic flow
(request → context → tools → checks → finish or retry), the harness's three jobs (before work,
during work, before finish), and one stop/check/retry example from oh-my-posh.
