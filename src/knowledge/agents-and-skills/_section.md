Two portable layers: `AGENTS.md` for instructions and `.agents/skills/` for skills. Covers
custom agents, agent modes (Ask / Plan / Agent), approval levels, handoffs, background and
cloud agent session types, and the `SKILL.md` file format. Skills are reusable, model-invoked
capability packages; agents are configured personas/roles with their own tools and permissions.

Source links:
- **code.claude.com → sub-agents** and **docs.github.com → custom agents**: official docs for
  Claude sub-agents and Copilot custom/cloud agents.
- **VS Code 1.109 release notes** and **VS Magazine (Feb 2026)**: multi-agent orchestration
  arriving in VS Code.
- **agentskills/agentskills**: the open skills standard; **anthropics/skills**,
  **github/awesome-copilot**, **obra/superpowers**: example skill collections; **skillsmp.com**:
  a skills marketplace/browser.
- **oh-my-posh/.agents/skills**: a live production skills folder.
