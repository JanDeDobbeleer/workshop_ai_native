Loops that let an agent run repeatedly against a goal. Starts from the "Ralph loop" (one year
old, deceptively simple), climbs a "loop ladder" where each level builds on the one below,
and stays honest about where loops pay off today — small, scoped automations, not the whole
SDLC — plus the infrastructure gap that still exists. Demoed with an agent definition that is
triggered automatically.
