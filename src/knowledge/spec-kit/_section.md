Spec-driven development with AI: treating specifications as version-controlled, executable
artifacts rather than throwaway docs. The idea is "version control for your thinking" — write
the spec, and the tooling drives implementation from it. Different tools share the same
philosophy; Spec Kit is CLI-based and template-driven ("install once, run the same commands
everywhere").
